#  Network Host Scanner

A Python tool for discovering active hosts on a local network using ICMP ping requests.This tool utilizes the standard socket interfaces to make and broadcast ICMP pings across a specified local subnet.


## 🎯 Purpose
Built to simulate network reconnaissance workflows utilized by security analysts to map an organization's internal attack surface and identify unauthorized devices.

 ## 📚 What I Learned
	∙	How ICMP ping works at a network level
	∙	IP address structure and subnetting basics
	∙	Python scripting for network tasks
	∙	How to identify active hosts on a network

## 🛠️ Tools Used
- Python 3
- subprocess (built-in)
- socket (built-in)

## 🚀 How to Run
```bash
python scanner.py
```
